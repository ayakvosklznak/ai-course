Здесь лежит **замороженный снимок** первой редакции курса «ИИ в работе IT-аналитика» (v1.0.1) — четыре файла-«книги», по части в каждом.

## Зачем это нужно

- Сохранить историю: как выглядел курс до разделения по главам и до унифицированной редакции.
- Дать возможность сравнить формулировки при переписывании глав.
- Не потерять версию, которую уже проходили читатели.

## Почему это архив, а не источник истины

Тот же текст в актуальном виде живёт в [content/course](../../../content/course/index.md), но разбит по главам и размечен front-matter:

| Здесь | Актуальная версия |
|---|---|
| [course_part_1.md](course_part_1.md) | [content/course/part-1](../../../content/course/part-1/index.md) |
| [course_part_2.md](course_part_2.md) | [content/course/part-2](../../../content/course/part-2/index.md) |
| [course_part_3.md](course_part_3.md) | [content/course/part-3](../../../content/course/part-3/index.md) |
| [course_part_4.md](course_part_4.md) | [content/course/part-4](../../../content/course/part-4/index.md) |

Содержательно это один и тот же материал. Отличия: заголовок главы перенесён в front-matter, уровень заголовков понижен на один, разделители `---` между главами убраны.

## Правила работы с архивом

1. **Не править содержимое.** Исправления вносятся только в `content/course`.
2. **Не добавлять новые главы.** Архив отражает конкретную версию.
3. **Ссылаться можно.** Для истории решений и сравнения формулировок.
4. **В README не выносить как основной материал.**
