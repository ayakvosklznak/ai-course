# Продуктовая упаковка курса

Этот документ описывает, как продавать текстовую версию курса на общем рынке. Он не является частью учебных материалов.

## 1. Позиционирование

**Не:** «курс по OpenCode», «курс про промпты», «универсальный курс для всех».

**А:**

> «AI-агент в инженерной работе» — практический воркбук, который за 90 минут даёт первый проверяемый результат, а за 20 часов — рабочую систему и комплект артефактов: `AGENTS.md`, skills, требования, спецификацию, ADR, проверки и ревью.

**Формула:** методология + шаблоны + проверяемые задания + ролевые треки. Инструмент — средство, а не продукт.

## 2. Аудитория

### Основная

- IT-специалисты с базовым Git и терминалом: разработчики, QA, DevOps/SRE, аналитики, менеджеры.
- Команды, которые внедряют Copilot, Cursor, Claude Code или OpenCode и не знают, как перейти от разрозненных промптов к процессу.

### Не целевая

- люди без опыта работы с файлами и терминалом;
- те, кто ищет только промпты или обзор нейросетей;
- senior ML-инженеры, которым нужна глубокая теория моделей;
- те, кто не может использовать агента по политике компании.

## 3. Боль и обещание

| Боль | Обещание |
|---|---|
| Агент выдаёт красивый, но непроверяемый текст | Научим проверять источники, diff и тесты |
| Каждый раз приходится объяснять контекст | `AGENTS.md`, skills и карта проекта |
| Непонятно, где заканчивается метод и начинается инструмент | Tool-agnostic ядро + labs под конкретные агенты |
| Команда работает по-разному | Ролевые треки и общий процесс |
| Риски безопасности и утечек | Отдельная часть про данные, секреты и prompt injection |

## 4. Что входит

| Компонент | Статус |
|---|---|
| Быстрый старт на 90 минут | Готов |
| 14 глав ядра | Каркас, текст собирается |
| 5 ролевых треков | Каркас, практика готова |
| 10 шаблонов артефактов | Готовы |
| Квизы и рубрика capstone | Готовы для глав 1–14 |
| Трекер прохождения квизов | Готов |
| Setup guide и проверка готовности | Готовы |
| Git-минимум для входного барьера | Готов |
| Sandbox-репозиторий | В плане |
| Эталонные артефакты и answer keys | В плане |
| Сертификат | В плане |

## 5. Продуктовая лестница

| Уровень | Что входит | Цена (гипотеза) | Цель |
|---|---|---:|---|
| Free | Быстрый старт, 3 шаблона, чек-лист | 0 | Лид-магнит |
| Starter | 6–8 ч: quick start + ядро | 4 900–9 900 ₽ | Первая покупка |
| Full | 20 ч + шаблоны + проверки + capstone | 14 900–24 900 ₽ | Основной продукт |
| Role lab | 2–3 ч под роль | 3 900–6 900 ₽ | Допродажа |
| Team | 5+ мест, внутренние права | от 60 000 ₽ | B2B |

Цены — гипотезы для проверки на пилоте, не обещание рынку.

## 6. Каналы

1. Собственный лендинг и Telegram-сообщество.
2. Stepik / GetCourse для РФ.
3. Gumroad / Leanpub для английской версии — после подтверждения спроса.
4. SEO-статьи: `AGENTS.md`, SDD, MCP и безопасность, AI-ревью.
5. Партнёрская программа с тимлидами и консультантами.
6. Корпоративные продажи после появления кейса.

## 7. Доказательства

До запуска нужно собрать:

- пилот на 15–25 человек;
- 3–5 отзывов с конкретными артефактами;
- один кейс с метрикой;
- статистику доходимости и сдачи capstone;
- публичный changelog и дату последней проверки;
- бесплатную главу и шаблон как демо.

Не публиковать вымышленные отзывы и метрики.

## 8. Метрики

| Метрика | Целевое значение |
|---|---:|
| Конверсия лендинга в покупку (тёплый трафик) | 2–5% |
| Доходимость до capstone | 40–50% |
| Возвраты | < 10% |
| NPS | > 40 |
| Обращения в поддержку | < 5% покупателей |
| Средняя оценка capstone | ≥ 1,5 из 2 |

## 9. План на 8 недель

| Недели | Работа |
|---|---|
| 1–2 | Позиционирование, структура, быстрый старт, лендинг, бесплатная глава |
| 3–4 | Переписать ядро: терминология, tool-agnostic, диаграммы, убрать дубли |
| 5 | Шаблоны, sandbox, автопроверки, квизы |
| 6 | Capstone, answer keys, сертификат, вёрстка PDF/EPUB |
| 7 | Пилот 15–25 человек, сбор метрик и отзывов |
| 8 | Упаковка, цены, запуск, партнёрская программа |

## 10. Риски

| Риск | Снижение |
|---|---|
| Привязка к OpenCode | Tool-agnostic ядро + labs |
| Нет доказательств эффекта | Пилот и кейс до масштабной продажи |
| Низкая доходимость текста | Quick start, квизы, capstone, напоминания |
| Конкуренция с бесплатным контентом | Шаблоны, проверки, ролевые треки |
| Юридические риски | EULA, политика возврата, privacy policy, оговорки о товарных знаках |
| Выгорание автора | Ограничить поддержку и заранее описать SLA |

## 11. Чего не обещать

- трудоустройство;
- гарантированный рост зарплаты;
- «освоите ИИ за 20 часов»;
- замену разработчика или аналитика агентом;
- сертификат государственного образца.
