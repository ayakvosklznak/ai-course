# Чек-лист ревью

> Шаблон для проверки артефакта или изменения, подготовленного человеком или агентом.

**Артефакт:** `<файл / PR / спецификация>`  
**Автор:** `<...>`  
**Ревьюер:** `<...>`  
**Дата:** `<YYYY-MM-DD>`

## 1. Источники

- [ ] Каждое существенное утверждение имеет источник.
- [ ] Источники актуальны.
- [ ] Противоречия между источниками зафиксированы.
- [ ] Допущения помечены.

## 2. Полнота

- [ ] Основной сценарий описан.
- [ ] Альтернативные сценарии описаны.
- [ ] Ошибочные сценарии описаны.
- [ ] Границы и исключения явные.
- [ ] Открытые вопросы не закрыты догадками.

## 3. Проверяемость

- [ ] У каждого критерия есть способ проверки.
- [ ] Проверки воспроизводимы.
- [ ] Доказательства приложены.
- [ ] Непроверенное явно названо.

## 4. Согласованность

- [ ] Нет противоречий внутри документа.
- [ ] Нет противоречий с требованиями и спецификацией.
- [ ] Ссылки актуальны.
- [ ] Терминология единообразна.

## 5. Решения

- [ ] Решение обосновано.
- [ ] Рассмотрены альтернативы.
- [ ] Последствия описаны.
- [ ] Владелец решения указан.

## 6. Безопасность

- [ ] Нет секретов и токенов.
- [ ] Нет лишних персональных данных.
- [ ] Права доступа минимальны.
- [ ] Необратимые действия требуют подтверждения.
- [ ] Риски prompt injection учтены.

## 7. Честность

- [ ] Неизвестное названо неизвестным.
- [ ] Ограничения перечислены.
- [ ] Стоимость и сроки не занижены.
- [ ] Нет ложной уверенности.

## 8. Ролевые дополнения

| Роль | Что проверить дополнительно |
|---|---|
| Разработчик | Diff, тесты, обратная совместимость, зависимости |
| QA | Покрытие, воспроизводимость, тестовые данные |
| DevOps / SRE | План отката, наблюдаемость, секреты, blast radius |
| Аналитик | Трассируемость, полнота требований, противоречия |
| Менеджер / продукт | Границы, риски, приоритет, приёмка |
