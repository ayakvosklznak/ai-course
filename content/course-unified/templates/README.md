В бесплатную версию входят:

- [AGENTS.template.md](AGENTS.template.md);
- [requirements.md](requirements.md);
- [review-checklist.md](review-checklist.md).

Остальные шаблоны — часть полной программы.

## Правила заполнения

1. Не оставляйте placeholder-ы в утверждённом документе.
2. Каждое существенное утверждение имеет источник.
3. Неизвестное оформляется как открытый вопрос, а не как факт.
4. Допущения помечаются явно.
5. У документа есть владелец, версия и дата.
6. Удаляйте разделы, которые не нужны для конкретной задачи.

## Как использовать в курсе

- Скопируйте нужный шаблон в `docs/` учебного репозитория.
- Заполните на основе источников и ответов владельца.
- Проведите ревью по [review-checklist.md](review-checklist.md).
- Свяжите документ с требованиями и проверками.
