## Как использовать

1. Пройдите главу.
2. Ответьте на вопросы квиза без подсказок.
3. Сверьтесь с ответами и разберите ошибки.
4. Выполните практику и проверьте себя по чек-листу.
5. Для итоговой работы используйте рубрику capstone.

## Обозначения

- По умолчанию у вопроса один верный ответ.
- Пометка **(несколько ответов)** в заголовке означает, что нужно выбрать все подходящие варианты.
- В ответах перечислены буквы всех верных вариантов.
- Для LMS и экспорта в PDF/EPUB эта пометка остаётся текстовой: так она читается в любом формате и не зависит от компонентов платформы.

## Принцип

Квиз проверяет понимание, практика — умение, capstone — способность довести работу до проверяемого результата. Оценка не должна зависеть от объёма текста, который сгенерировал агент.
