**Время:** 10 минут.

Курс рассчитан на специалистов с базовым опытом работы в терминале и Git. Проверьте себя до покупки или начала, чтобы не тратить время на борьбу с окружением.

## Чек-лист

Отметьте то, что уже умеете:

- [ ] Открыть терминал и перейти в нужную папку.
- [ ] Создать папку и файл.
- [ ] Прочитать `git status` и `git diff`.
- [ ] Сделать коммит.
- [ ] Откатить изменение через `git restore`.
- [ ] Прочитать Markdown и JSON.
- [ ] Установить программу через пакетный менеджер.
- [ ] Настроить переменную окружения.
- [ ] Сформулировать задачу с критерием результата.
- [ ] Отличить факт от предположения в тексте.

## Как оценить

| Баллы | Что делать |
|---:|---|
| 9–10 | Можно начинать с быстрого старта |
| 6–8 | Начните с быстрого старта и закройте пробелы по setup guide |
| 3–5 | Сначала пройдите мини-курс по Git и терминалу |
| 0–2 | Курс пока не подходит; начните с основ работы с компьютером и Git |

## Что не требуется

- умение программировать на уровне разработчика;
- опыт машинного обучения;
- знание конкретной модели;
- доступ к дорогой инфраструктуре.

## Что требуется обязательно

- доступ к CLI-агенту и модели;
- разрешение использовать выбранный инструмент на рабочем оборудовании;
- понимание политики компании по работе с данными;
- 20 часов на полную программу или 90 минут на быстрый старт.
