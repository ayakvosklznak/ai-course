**Время:** 20–30 минут.

Этот раздел закрывает минимальный входной барьер. Он не заменяет полноценный Git-курс, но даёт команды, без которых нельзя безопасно работать с агентом.

## Зачем Git

- Показать, что именно изменил агент.
- Откатить лишнее.
- Сохранить проверенный результат.
- Вернуться к предыдущей версии.

## Проверка

```bash
git --version
```

## Основные команды

```bash
git status --short
git diff
git add <файл>
git commit -m "docs: describe change"
git restore <файл>
git switch -c experiment
```

## Безопасный цикл

1. Проверить состояние: `git status --short`.
2. Прочитать изменения: `git diff`.
3. Добавить только нужное: `git add <файл>`.
4. Зафиксировать: `git commit -m "..."`.
5. Если что-то пошло не так: `git restore <файл>`.

## Что нельзя делать без понимания

- `git reset --hard` — удаляет незакоммиченные изменения.
- `git push --force` — переписывает удалённую историю.
- Удаление `.git` — уничтожает историю.
- Коммит `.env`, ключей и токенов.

## Мини-практика

1. Создайте файл и сделайте коммит.
2. Измените две строки.
3. Посмотрите `git diff`.
4. Откатите одну строку через `git restore`.
5. Сделайте новый коммит.
