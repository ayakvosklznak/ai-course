**Время:** 15–30 минут.

Этот guide вынесен из основного курса, потому что команды установки и интерфейсы инструментов меняются чаще, чем методология. Перед выполнением сверяйтесь с официальной документацией выбранного агента.

## Что нужно

| Компонент | Зачем | Проверка |
|---|---|---|
| Git | Версии, diff, откат | `git --version` |
| Node.js и npm | Установка CLI-агента | `node --version`, `npm --version` |
| CLI-агент | Работа с файлами проекта | `opencode --version` |
| Доступ к модели | Генерация и анализ | Простой запрос в агенте |
| Терминал | Команды курса | `pwd`, `ls -la` |

## Windows

1. Установите Git for Windows и откройте **Git Bash**.
2. Установите Node.js LTS.
3. Проверьте команды:

```bash
git --version
node --version
npm --version
```

4. Установите CLI-агент по официальной инструкции. Для OpenCode 2 используется пакет `@opencode/cli`:

```bash
npm install -g @opencode/cli
opencode --version
```

5. Если команда `opencode` не найдена, проверьте PATH и перезапустите терминал.

## macOS

1. Установите Git и Node.js LTS.
2. Проверьте версии теми же командами.
3. Установите агент по официальной инструкции.
4. Убедитесь, что `opencode --version` выводит ожидаемую версию.

## Подключение модели

Возможные варианты:

- подписка провайдера;
- API-ключ;
- локальная модель через совместимый сервер.

Правила:

- ключ хранится в переменной окружения или менеджере секретов;
- ключ не попадает в репозиторий, логи и скриншоты;
- для учебного проекта используйте отдельный ключ с минимальными правами;
- при завершении работы отзывайте ненужные ключи.

## Разрешения агента

Настройте подтверждения для:

- изменения файлов;
- выполнения команд;
- сетевых вызовов;
- необратимых действий: удаление, публикация, миграции.

Запретите агенту доступ к:

- домашним каталогам вне проекта;
- файлам `.env` и хранилищам секретов;
- продуктовым окружениям и чужим репозиториям.

## Проверка

```bash
pwd
ls -la
git status --short
opencode --version
```

Затем запустите агента из корня учебного проекта и попросите перечислить файлы. Он должен видеть только проект.

## Диагностика

| Симптом | Что проверить |
|---|---|
| `opencode: command not found` | PATH, глобальные пакеты npm, перезапуск терминала |
| Ошибка авторизации | Провайдер, ключ, срок действия, сеть |
| Модель не отвечает | Лимиты, выбранная модель, регион |
| Агент не видит файлы | Рабочий каталог, права, `.gitignore` |
| Установилась не та версия | `opencode --version`, список глобальных пакетов |

## Безопасность

- Не запускайте установку и настройку в спешке.
- Не вставляйте ключи в чат с агентом.
- Не используйте рабочий репозиторий для экспериментов.
- Перед рискованными действиями сделайте резервную копию или коммит.
